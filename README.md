# ⚽ Football Turf Booking Platform

A premium, mobile-first web application for real-time football turf reservations. Built with modern web technologies, it features a sleek dark-mode UI, secure admin controls, and automated WhatsApp integration for booking inquiries.

## 🚀 Live Demo
**[Launch Live Website](https://football-turf.onrender.com)**

---

## ✨ Features
- **📱 Mobile-First Design**: Optimized for a seamless experience on all devices with 4-column compact layouts.
- **📅 24/7 Real-Time Availability**: Instant slot generation for every hour of the week (00:00 - 23:00).
- **🔒 Secure Admin Panel**: Full dashboard at `/admin.com` to manage bookings and toggle slot statuses.
- **💬 WhatsApp Integration**: Direct inquiry redirection for instant communication with turf owners.
- **☁️ Cloud Powered**: Backed by **PostgreSQL** (Supabase) and hosted on **Render** / **Vercel**.

## 🛠️ Tech Stack
- **Frontend**: React.js, Vite, Lucide Icons
- **Backend**: Express.js, Node.js
- **Database**: PostgreSQL (via Supabase)
- **Styling**: Vanilla CSS (Modern CSS System)

## 📦 Local Setup
1. Clone the repository
2. Install dependencies: `npm install`
3. Set `DATABASE_URL` in your environment.
4. Run development server: `npm run dev`
5. Run backend: `npm start`
